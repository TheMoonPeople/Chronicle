# The functions of ps2/src that fall off their end, and what the GCC build returns there.
#
# MWCC returned whatever v0 held and clang's -fno-strict-return keeps that undefined but harmless;
# GCC has no such flag and assumes the end cannot be reached, so it drops the branches that lead
# there or runs into the next function. fall_off_returns.py writes `return <value>;` at the end of
# each of these in the build's copy of the unit. The GCC build compiles ps2/src with
# -Werror=return-type, so a function that starts falling off its end stops the build until it is
# listed here.
#
